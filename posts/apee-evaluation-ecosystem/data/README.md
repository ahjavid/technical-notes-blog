# Data: APEE Evaluation Runs

Results behind [APEE: Evaluating Multi-Agent LLM Systems with LLM-as-a-Judge](../index.md).

## The December 11, 2025 runs

Four complete runs of all 12 scenarios with the same three agents (`qwen2.5-coder:3b`, `llama3.2:3b`, `phi4-mini:3.8b`) and two judges (`gpt-oss:20b`, `mistral-small3.2:24b`):

| File | Run | Started |
|---|---|---|
| [`apee_evaluation_results.json`](apee_evaluation_results.json) | 1: basic ensemble only | 12:56 |
| [`apee_evaluation_results_progressive.json`](apee_evaluation_results_progressive.json) | 2: basic ensemble + progressive deepening | 13:23 |
| [`apee_evaluation_results_jury.json`](apee_evaluation_results_jury.json) | 3: basic ensemble + persona jury | 14:08 |
| [`apee_evaluation_results_calibrated.json`](apee_evaluation_results_calibrated.json) | 4: basic ensemble + calibrated jury | 14:56 |

> [!IMPORTANT]
> The file names suggest four evaluation modes, but `overall_apee_score` comes from the same basic two-judge ensemble in all four files. Each run re-executed the agents, so differences between files in `overall_apee_score` reflect run-to-run variation. To compare judging protocols, use `advanced_evaluation` (runs 2–4), which holds each protocol's own scores for the same agent outputs.

Each file contains `timestamp`, `evaluation_mode`, `judge_models`, `agent_models` and a list of `scenarios`. Each scenario entry has these fields:

| Field | Meaning |
|---|---|
| `scenario_id`, `pattern` | The scenario and the coordination pattern it used |
| `duration_seconds` | Wall time the agents needed for the scenario |
| `overall_apee_score` | 0.30 × L1 + 0.45 × L2 + 0.25 × L3, on a 0–10 scale |
| `level1_individual` | Goal alignment and semantic quality for each agent, with the judges' written feedback; `average` is L1 |
| `level2_collaborative` | Collaboration effectiveness and synthesis quality, with feedback; `average` is L2 |
| `level3_ecosystem` | Computed efficiency, stability, throughput and adaptability; `overall` is L3 |
| `ensemble_metadata` | Each judge's own scores and the disagreement between the two judges |
| `advanced_evaluation` | Runs 2–4 only: the extra protocol's score for every agent, plus `average_score` |

## Loading the data

```python
import json

with open("apee_evaluation_results_jury.json") as f:
    run = json.load(f)

for scenario in run["scenarios"]:
    print(
        scenario["scenario_id"],
        scenario["overall_apee_score"],                     # basic ensemble
        scenario["advanced_evaluation"]["average_score"],   # persona jury
    )
```
